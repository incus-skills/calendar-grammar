## Current Position on Pilgrimage

### 1. Pilgrimage as Scheduled Re-entry

Pilgrimage provides a **temporal-spatial re-entry surface**:

| Function      | Description                                                                                  |
| ------------- | -------------------------------------------------------------------------------------------- |
| **Scheduled** | Pilgrimage cycles are tied to the calendar backbone—annual, generational, or epochal         |
| **Embodied**  | Pilgrimage requires physical movement, effort, and presence                                  |
| **Traversal** | Pilgrimage moves participants through space and time, mirroring the calendar's nested cycles |
| **Re-entry**  | Pilgrimage re-positions the observer within the ecology                                      |

### 2. Pilgrimage as Laminar Transition

The laminar flow metaphor applies directly:

| Condition                           | Outcome                                                   |
| ----------------------------------- | --------------------------------------------------------- |
| **Pre-oriented participants**       | Pilgrimage becomes a coherent passage through constraint  |
| **Disoriented participants**        | Pilgrimage induces turbulence or fragmentation            |
| **Recursively entrained community** | Pilgrimage accelerates coherence through shared traversal |

### 3. Pilgrimage as Training and Competition

The pilgrimage has been extended into a **training system, social competition, and rite of passage**:

| Function              | Description                                                                       |

| **Competition**       | Pilgrimage as a race or contest against peers or against one's own best time      |
| **Rite of Passage**   | Pilgrimage as a test—coming of age, proving readiness, earning status             |
| **Re-entry Vehicle**  | Pilgrimage as a secularly framed activity that preserves the ecological structure |
