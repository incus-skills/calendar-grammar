## The Four Stages of Hypnotic TOTE

### 1. Test 1: Establishing Criteria (The Trigger)

The suggestion begins by defining the **desired state** or criteria for success. This acts as the "feed-forward" mechanism.

- **Function:** It sets the standard against which all subsequent experiences will be measured.
- **Hypnotic Application:** Instead of commanding "Relax now," the operator establishes a criterion: "You will know you are entering a useful state when you notice a specific shift in your breathing." This creates a **reference signal** for the unconscious to monitor.

### 2. Operate: Gathering and Altering Data

If the current state does not match the criteria (Test 1), the system enters the **Operate** phase.

- **Function:** This involves accessing internal/external data, performing actions, or generating new representations to reduce the gap between the current state and the desired state.
- **Hypnotic Application:** The subject unconsciously (or consciously) attempts various internal strategies—visualizing, recalling memories, or shifting focus—to meet the criteria. In generative grammar, this is where **nested narratives** or **confusion techniques** provide the "operations" or data shifts needed to bridge the gap.

### 3. Test 2: Comparison and Feedback

The system compares the result of the operation against the original criteria established in Test 1.

- **Function:** This is the critical **feedback loop**. It asks: "Does the current experience match the desired criteria?"
- **Hypnotic Application:** If the match is insufficient, the loop recycles to the **Operate** phase with adjusted parameters (e.g., trying a different memory or sensory modality). If the match is successful, the system proceeds to Exit. This ensures the suggestion is only "accepted" when the subject's internal reality aligns with the proposed frame.

### 4. Exit: The Decision Point

When Test 2 confirms a match, the loop terminates, and the system moves to the next state.

- **Function:** This locks in the change and releases the cognitive tension held by the open loop.
- **Hypnotic Application:** The "Exit" is often marked by a physical cue (a sigh, a hand drop) or a linguistic marker ("And now you can allow that new understanding to settle"). This signals the completion of the strategy and stabilizes the new observer position.
